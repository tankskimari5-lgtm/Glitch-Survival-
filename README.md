# GLITCH SURVIVAL — 2D Reboot

A mobile-friendly **top-down 2D survival game** built with HTML Canvas. The previous 3D prototype has been replaced.

## Play
https://glitch-survival.vercel.app/

## Gameplay
Explore, gather wood/stone/fiber, loot supply crates, fight wandering zombies, craft axes and tools, wear clothing and build a base. Health, hunger, thirst, stamina and day/night all matter; progress saves in the browser.

## Controls
**Mobile:** left joystick moves, GATHER collects resources, ATTACK fights. PACK, CRAFT, BUILD and GEAR open menus.

**Desktop:** WASD or arrow keys, E to gather, Space to attack, I backpack, C craft, B build, G equipment, 1–5 quick items.

## Files
- index.html — complete standalone game.
- afterfall_survival.html — identical 2D alias retained for an older Vercel homepage rewrite.
- game.js / style.css — readable split sources.

No external game engine or 3D models are required. Saved progress uses localStorage key `glitch-survival-2d-v1`.

The old 3D versions are archived in the owner's ChatGPT Library, not in this repository.
